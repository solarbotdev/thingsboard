# solarbotdev/thingsboard

SolarBot's fork of [ThingsBoard CE](https://github.com/thingsboard/thingsboard):
the official `tb-node` image with a SolarBot-branded web UI, published as
`ghcr.io/solarbotdev/tb-node:<version>-solarbot.<N>`.

This default branch (`solarbot/main`) holds only the build tooling. The
source lives on the `solarbot/v<upstream tag>` branches; `master` mirrors
upstream. See [solarbot/README.md](solarbot/README.md).
